# ListaDo

Aplicación web para gestionar tareas universitarias, organizar materias,
registrar clases con apuntes/imágenes, y priorizar entregas.

## Tecnologías

- **Frontend:** HTML, CSS (Tailwind), JavaScript
- **Backend:** Node.js, Express.js
- **Base de datos:** Supabase (PostgreSQL)
- **Almacenamiento de imágenes:** Supabase Storage

## Instalación

1. Clona el repositorio:
```bash
   git clone https://github.com/TU_USUARIO/listtodo.git
   cd listtodo
```

2. Instala las dependencias:
```bash
   npm install
```

3. Crea un archivo `.env` con tus credenciales:
```
   SUPABASE_URL=tu_url_aqui
   SUPABASE_KEY=tu_key_aqui
```

4. Inicia el servidor en modo desarrollo:
```bash
   npm run dev
```
